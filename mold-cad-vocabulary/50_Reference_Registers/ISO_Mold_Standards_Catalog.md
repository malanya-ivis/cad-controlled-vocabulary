## Nearby standards not adopted as injection-mold vocabulary

- [[ISO_10303_224_Machining_Features_Record]]: machining-feature exchange model; useful for CAD/manufacturing boundaries, not a mold-component glossary.
- [[ISO_10303_42_Geometry_Record]]: general geometry/topology representation, including B-rep and tessellated geometry; not a mold-feature vocabulary.
- [[ISO_22432_Features_Record]]: geometrical features used in specification and verification; a category reference, not a complete mold-CAD term list.
- [[ISO_1101_Geometrical_Tolerancing_Record]]: geometrical tolerancing and 3D CAD specification context; detailed clauses remain unread.
- [[ISO_21920_2_Surface_Texture_Record]]: profile surface-texture terms and parameters; a new edition is under development, so recheck status before detailed use.
- [[ISO_25964_2_Interoperability_Record]]: abstract-level thesaurus interoperability reference; not read as an implementation guide.
- Foundry vocabulary standards belong to another manufacturing domain and remain out of this injection-molding batch.

## Reading and reuse rule

The register is an index, not evidence that the standard text was read. Preserve the source-specific reading state and usage constraints in each note. No dimensions, complete tables, definitions, or figures from paid standards are stored here.

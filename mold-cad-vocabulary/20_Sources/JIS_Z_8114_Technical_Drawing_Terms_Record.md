# JIS Z 8114:1999 — Technical Drawing Terms Record

## Source and reading scope

- Organization: Japanese Standards Association (JSA)
- Official catalog: https://webdesk.jsa.or.jp/books/W11M0090/index/?bunsyo_id=JIS+Z+8114%3A1999
- Standard: JIS Z 8114:1999, 製図―製図用語 (Technical product documentation — Terms relating to technical drawings)
- Catalog status: JSA lists the standard as effective and records confirmation on 2024-06-20; checked 2026-10-06.
- Scope shown in catalog: definitions of terms used in product technical documentation relating to technical drawings.
- Reading scope / date: Official JSA catalog page only; the standard text was not read; 2026-10-06.
- Usage conditions and saved material: The full standard is sold by JSA. This note stores catalog metadata and a short independent scope summary only; no standard text or tables are copied.

## Use in this project

Use this as a Japanese terminology and scope reference for drawing-related language. Compare individual terms only after the relevant standard clauses are accessed and read. Its title and scope do not establish that it is a complete 3D CAD feature taxonomy.

The JSA catalog records correspondence with ISO 10209-1:1992 and ISO 10209-2:1993 as modified (MOD). This is catalog metadata, not a clause-level comparison.

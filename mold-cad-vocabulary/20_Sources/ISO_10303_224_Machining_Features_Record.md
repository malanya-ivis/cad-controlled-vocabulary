## Scope clarification added 2026-10-06

The [official ISO record](https://www.iso.org/standard/36000.html) describes AP 224 as an application protocol for representing and exchanging manufacturing information for single-piece mechanical parts, including explicit and implicit machining-feature shape representations. This is a technical representation/process-planning reference, not an existing controlled vocabulary for general mold-CAD geometry. The standard text remains unread.

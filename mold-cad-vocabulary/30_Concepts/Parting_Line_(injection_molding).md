# Parting Line (injection molding)

> Context only: retained from the earlier mold-component/process study; this note is outside the active single-part shape-feature set.


## Definition and scope

[Source-supported draft / injection-molding scope] The boundary/interface established where mold portions meet and separate. JEED's explanation calls the mating surface between the convex Core component and concave Cavity component a パーティングライン; MISUMI also uses “parting surface.” Because one source label refers to a surface while its English name says “line,” this note keeps line, surface, and interface readings visible rather than treating them as interchangeable geometry.

## Broader concept

Not established.

## Related or distinguished concepts

- [[Core_(mold_component)|Core]] and [[Cavity_(injection_molding)|Cavity]]: complementary mold portions whose meeting interface is described by JEED.
- [[Gas_Vent_(injection_mold)|Gas Vent]]: venting may use a split interface, but the parting interface is not itself necessarily a vent.
- [[Undercut_(injection_molding)|Undercut]]: parting design can affect release feasibility; the terms describe different design concerns.

# Mold Base

> Context only: retained from the earlier mold-component/process study; this note is outside the active single-part shape-feature set.


## Definition and scope

[Source-supported draft / injection-molding scope] This note selects the supporting assembly of plates/components that houses cavity-forming parts and mounts the mold to the injection-molding machine. MISUMI identifies a mold-base set with plates, spacers, and ejector components; JEED's selected glossary entry uses `モールドベース` more broadly for the housing of mold structural elements and even the mold body. Keep that wider source use visible rather than assuming all sources mean only the base plate set.

## Broader concept

Not established. The boundary between the Mold Base assembly and the complete mold is source-dependent and needs a project decision.

## Related or distinguished concepts

- [[Core_(mold_component)|Core]] and [[Cavity_(injection_molding)|Cavity]]: forming components/regions housed or supported within the mold structure.
- [[Ejector_Pin]]: one ejection component used with the base assembly.
- [[Ejector_Plate]]: listed among mold-base components in MISUMI's article.
- [[Sprue_Bushing]]: a feed-system component that may be installed in the assembly.
- [[Mold_Insert_(injection_molding)|Mold Insert]]: JEED describes a divided cavity portion fitted into the Mold Base.
- JIS B 5101:2003 is listed in the JSA mold handbook indexes as a mold-use machined-plate standard. This is a component-family pointer only; the catalog does not define the whole Mold Base assembly.

# Core (mold component)

> Context only: retained from the earlier mold-component/process study; this note is outside the active single-part shape-feature set.


## Definition and scope

[Source-supported draft / injection-molding scope] A mold component or side that forms the inside of a molded part. JEED describes the convex Core part as complementary to the concave Cavity part; Shibaura describes a male mold part used to form the product interior and notes that a core may also form an undercut. MISUMI discusses Core as a forming component that may be integral or split into assembled pieces. This note does not mean any generic solid, the Core Pin, or the entire moving half of a mold.

## Broader concept

Not established. The source supports a mold-component sense but does not provide the project's full hierarchy.

## Related or distinguished concepts

- [[Cavity_(injection_molding)|Cavity]]: complementary forming context. JEED uses Cavity for the concave component in one explanation, while Shibaura also uses the same label for the forming space; this note keeps Core as a component.
- [[Core_Pin]]: a more specific pin-shaped mold component in the Autodesk glossary; not equivalent to every Core component.
- [[Mold_Insert_(injection_molding)|Mold Insert]]: construction as a fitted piece is distinct from the forming role of Core.
- [[Hole]]: a core pin may create a hole according to the glossary, but the mold component Core is not the resulting Hole and should not be merged with it.

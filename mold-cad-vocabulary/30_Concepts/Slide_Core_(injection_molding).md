# Slide Core (injection molding)

> Context only: retained from the earlier mold-component/process study; this note is outside the active single-part shape-feature set.


## Definition and scope

[Source-supported draft / injection-molding scope] A movable core component that shifts to release an undercut; JEED and Shibaura describe it as driven by an angled pin during mold opening/closing. This is a mold mechanism component, not the product's undercut condition or the main Core concept generally.

## Broader concept

Not established. A hierarchy of movable mold cores has not been defined.

## Related or distinguished concepts

- [[Core_(mold_component)|Core]]: related forming component; a Slide Core is movable to release an undercut.
- [[Angled_Pin_(injection_molding)|Angled Pin]]: drives the Slide Core in the cited sources.
- [[Undercut_(injection_molding)|Undercut]]: product geometry/release condition that motivates the mechanism.

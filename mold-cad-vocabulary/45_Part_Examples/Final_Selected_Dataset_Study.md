# 複雑なSTLへの用語の適用

対象は `/home/malanya/projects/cad-structure-search/data/final_selected/stl` の93ファイルです。全93件の外観図と外形寸法を保存し、下の四件を断面まで調べました。93件すべての特徴を分類したわけではありません。

ファイル一覧の `flat_plate / elongated / isotropic / irregular` は全体の形の分類です。穴や長穴などの特徴、金型の用途を示すラベルではありません。

| 部品 | 用語を使った例 | 記述で分かった注意点 |
|---|---|---|
| [[CAD_1400_Hole_Relations|1400]] | 四つの貫通穴 | 選んだ断面では交差を認めない。全体の交差・接続は未確認 |
| [[CAD_4423_Open_Void|4423]] | 開口した空間・ポケット・肉厚 | 同じ空間を二重に数えない。閉じたメッシュでも空間は開口できる |
| [[CAD_8972_Slot_and_Recesses|8972]] | 段付きの長穴・矩形の凹部 | 六つの凹部をすべて「止まり」と書くと誤りになる |
| [[CAD_7145_Fillet_and_Internal_Structure|7145]] | 外側の丸み・内部の空間 | 外観だけでは内部の空間が分からない |

## 六つの補充項目との関係

| 項目 | 今回できたこと | 残ること |
|---|---|---|
| 実際の部品の記述 | 四件に特徴ID・形・関係・根拠を付けた | 実際の金型部品かどうかの確認 |
| 似た形の比較 | [[Shape_Comparison_Examples]] に座ぐり／皿ざぐり、ポケット／長穴、フィレット／面取りを整理。2026-10-07に[[CAD_Rib_Boss_Comparison]]を追加 | 一般的なBossの定義と用語の境界の確認 |
| 形の違い | 貫通・有底・底が一部残る・開口・段付きという属性を記録。[[CAD_Enclosed_Open_Void_Teaching]]で開閉を比較 | 実部品の確認済み閉鎖空洞、曲線の長穴 |
| 日本語名の統一 | 既存の15概念IDを使い、名称候補を合わせた | 日本語名と同義語の正式な確認 |
| 用途と根拠 | 観察した形と未確認の用途を分けた | 図面・設計者の説明による用途の確認 |
| 実際の検索例 | JSONに特徴・属性・関係の確認結果を保存した | CAD検索システムとRAGへの実装 |

4423の肉厚値は、底面間をZ方向、直線側壁を中央断面で壁面に垂直な方向に測った局所値です。最小値ではありません。8972の背面側厚さも、凹部床と背面の間をY方向に測った局所値です。測定法の詳細は各部品例とJSONに記録します。

## 課題3への使い方

[[Final_Selected_Feature_Records.json]] は、データベースに入れる項目を考えるための小さな例です。部品ID、特徴ID、概念ID、属性、関係、根拠を保存します。

| 検索したい内容 | 必要な条件 | この記録で対応する例 |
|---|---|---|
| 段付きの貫通長穴 | MC-005、termination=through、entrance_step=true | 8972のF01 |
| 底が一部だけ残る凹部 | floor_state=partial | 8972のF07 |
| +Z側に開いた空間 | MC-013、opening_direction=+Z | 4423のF01 |
| フィレットと内部空間の両方がある部品 | 同じ部品にMC-008とMC-013 | 7145 |
| 穴同士が内部でつながる部品 | 接続を全体の形状根拠で確認した関係 | 1400は選択断面で交差を確認できなかったが、全体判定はunknown。他の部品も未確認なら除外の根拠にしない |

RAGでは条件に合う記録を探し、その記録と断面の根拠を回答に使う流れを検討できます。このvaultは語彙・記述例・根拠を準備する場所です。検索エンジンやRAGの実装はまだありません。

2026-10-07に[[RAG_Search_Verification_Cases]]を追加しました。19問を手動JSONの条件絞り込みで確認する例です。Q13とQ19は1400のunknownを保ち、Q14～Q17は単位・用途・方向の不足を返します。DB・RAGの実装や、CAD形状の再認識ではありません。
